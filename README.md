# Last Man Standing

[timhelps.github.io/lms](https://timhelps.github.io/lms/)

Teams ranked by Elo. Win-or-draw % is from bookmaker odds for this matchweek’s game (loaded when you open the page).

Refresh ratings: `python3 scripts/fetch_elo.py`, then commit `data/elo.json`.

Local: `python3 -m http.server 8080`
